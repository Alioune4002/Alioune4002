# Alioune Seck

Développeur web freelance. Je crée des sites et des outils métier pour les indépendants et petites entreprises, et je peux aussi reprendre un projet déjà commencé.

Je travaille notamment sur des besoins de **réservation, paiement, e-commerce, back-office, automatisation et applications web sur mesure**.

## Ce que je fais

**Créer** : site vitrine, boutique, réservation ou première application web.

**Simplifier** : transformer des tâches encore gérées par messages, tableaux ou outils séparés en parcours plus simples.

**Reprendre** : débloquer ou terminer un projet existant, qu'il ait été commencé avec une IA, du no-code ou un autre développeur.
